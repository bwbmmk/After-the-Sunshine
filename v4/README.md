# 留一盏灯 · 漫游版

《晴天以后》的新篇章。一学期、一部还没剪完的短片，以及几个慢慢熟悉的人。

在完整的五章剧本之上，加了**自由行动 / 可交互人物 / 校园地图 / 委托手账**四层玩法。
主线里原来的 14 处「当场二选一」全部拆掉了——现在故事的走向不是当场点出来的，
而是你在章节之间的空档里、把有限的时间花在谁身上换来的。

## 开始

双击 `dist/留一盏灯·漫游版.html`。不需要安装、不需要联网。

已经打好的成品在 `../成品/`：

- 同一人物有多个委托时，选“先不了”后继续听后面的事。
- 离开漫游会提醒尚未交差的分路委托，明确“答应”和“完成”的区别。

## 玩法

### 主线

点一下补完文字，空格或 Enter 推进，返回按钮回退。主线里已经没有当场选项了：
十四处分岔各剩一段旁白，通向哪条支线由世界里的 flag 决定。

### 自由行动

主线走到五个章节边界会进入自由行动（报到日 / 十月 / 十一月 / 十二月 / 一月）。
漫游层接管画面：对话框收起，场景上直接出现此刻在这里的人。

- **点人物**：场景里的圆头像就是在这里的人，点谁和谁聊。首次见面有专门的打招呼
  （好感 +1，每窗口一次），常聊天会提升熟络度（每人满 5 心）。
  **同一个人手上还压着没办完的事，就不会再开口拜托下一件**；一次对话也最多说一件新委托。
- **M 校园地图**：14 处地点的手绘导览，点哪里去哪里；橙点表示那里有委托找你，
  ★ 是当前主线目的地，一撮小亮点表示那儿有个能顺手捡的东西。
- **J 任务手账**：手上的委托、这个月没做的、听说的事、已完成、六个人的熟悉度。
- **口袋**（顶栏 ▤）：分三栏——手上的事 / 留念 / 角落里的小东西，外加一叠纸片。

### 精力有限：互斥组

29 条委托分成 10 个互斥组，每组对应一处主线分岔。**接了组里的一件，同组其余几件
这个月就作废**（手账里标为「这个月没空」，并且不会再出现）。这不是惩罚，是这一版
最主要的表达方式：

| 窗口 | 互斥组 | 决定的主线走向 |
| --- | --- | --- |
| 报到日 | 这个下午给谁 | `first` → 拍空间 / 拍人 |
| 报到日 | 今晚的灯 | `agreement` → 借灯 / 不借 |
| 十月 | 跟着什么拍 | `focus` → 拍人 / 拍地方 |
| 十月 | 钱和跑腿 | `budget` → 小预算 / 一起垫 |
| 十月 | 录音笔记什么 | `record` → 只录环境声 / 先审一遍 |
| 十一月 | 片子怎么改 | `review` → 先撤下来 / 约人对表 |
| 十一月 | 六块钱和排班 | `care` → 排班还 / 各自分担 |
| 十二月 | 在哪儿放 | `venue` → 走官方流程 / 借小教室 |
| 十二月 | 今晚停不停 | `night` → 停 / 搬去自习室 |
| 一月 | 放完以后 | `release` → 公开 / 只办一场 / 留给下一届 |

另外四处主线分岔（`time` / `home` / `credit` / `intro`）不单独设组，由已经定下的方向推出来。

### 道具：拿到 → 收进口袋 → 交付时给出去

任务道具不再是一句"任务完成"就没了。每件东西都会被真的拿在手上，看得见它进袋、
也看得见它交出去（收下时飞进口袋按钮，交出时飞向对话人）。

两条长链横跨整个学期：

- **螺丝链**（十二月 · 程野 → 陈姨 → 程野）：从程野手里拿一袋 M6 螺丝 →
  交给食堂陈姨 → 换回四片垫片和一张纸条 → 垫片交回程野 → 换回装螺丝的旧铁盒。
- **申请表链**（十二月 · 陈姨 → 阿言 → 陈姨 · 五步）：手写草稿 → 交给阿言调格式 →
  回食堂取两寸照片 → 照片交回阿言 → 打印好交回陈姨 → 留下一份复印件。

还有两条**跨委托链**：十月「编号 089」拿到的一卷编号胶带，要到十二月
「一柜子的线」才用得上；十二月复印的那份申请表，一月才归进阿言的交接文件夹。
没拿到前一件，后一件在委托列表里就是 `locked`（还没到时候）。

### 好感与专属留念物

六个人都有 5 心熟络度。**满 5 心之后再去说一次话**，会触发一段只属于你们两个人的对话——
先是**整屏 CG**（暗场 + 缓慢推镜 + 一道扫光 + 字幕逐级浮现，点击 / Esc / 空格收起），
再回到对话，这个人把专属留念物交给你——每人一件，只给一次：

| 人物 | 留念物 |
| --- | --- |
| 小满 | 一张空杯子的照片 |
| 程野 | 一把蓝色手柄的螺丝刀 |
| 阿言 | 一根转接线 |
| 陈姨 | 写着「耳东陈」的纸条 |
| 周老师 | 一本翻旧的讲义 |
| 妈妈 | 一张短信截图的打印版 |

CG 由 `assets/cg/*.png` 经 `tools/pack-cg.py` 压缩内嵌（`js/cgdata.js`，480px / JPEG q72）；
手账「熟悉的人」里拿过留念物的常驻 CG 头像，点一下可以再整屏看一次。

好感有三个来源：每个窗口第一次聊天 +1；完成谁拜托的委托 +2；委托链上经手过的人各 +1。
妈妈没有委托，但五个窗口都会打电话来（在四号楼接），五通电话刚好 5 心；
周老师十月到十二月都在教学楼、一月在礼堂，再经手一件有他参与的委托即可满。

常驻寒暄也随好感分档：0–2 心是还客气着的口气，3 心以上换成另一种说法。

## 文本分层

对白、旁白、心声是三种不同的声音，数据与渲染都分开处理。

- **写作侧**用四个构造器：`D()` 对白 · `S(who, …)` 旁白里提到某人 · `N()` 旁白 · `I()` 心声。
- **兜底**：老写法（一整段纯文本）仍然能用。`bare(text, who)` 扫描中文引号 `“ ” 「 」` 的嵌套深度，
  自动把它切成旁白 / 对白，所以漏写分段也不会露馅。
- **双轨产出**：`beat()` 一次性生成 `node.seg`（分段，渲染用）与 `node.text`（扁平字符串，
  故事记录 / 导出 / 结局卡 / 旧存档都读它）。`validate-story.mjs` 有永久断言，两者一旦漂移就报错。
- **渲染**：`engine.setText(segs)` 为每一段建一个 `<span class="seg seg-{k}">`，
  打字机按「整串偏移」灌字，所以逐段显示不会串行。
- **视觉**走三个通道：明度（旁白压到 72%）、字重（对白 600）、字体（心声走衬线）；
  六位常出场人物再叠一层 `[data-who]` 色相偏移。全部用 `color-mix()` 写，夜读界面自动跟着变。

当前剧本 657 段：旁白 339 · 心声 179 · 对白 139，正文约 10,000 字。

## 本版内容

- **内容数据层** `js/quests.js`：31 件物品（任务 11 / 校园小物 14 / 留念 6）、
  10 个互斥组、29 条委托、29 张手记、6 段专属对话。
- **世界规则层** `js/game.js`：14 地点 / 道路 / 5 个窗口 / 6 人物日程 /
  `questState()` 六态（done / ready / active / abandoned / locked / offer）/
  `derivedFlags()` 把做完的委托汇总成主线能读的 flag / `flagSamples()` 造 1536 组取值样本。
- **漫游呈现层** `js/roam.js`：旅行、对话队列、道具取交动画、互斥提示、手账、地图、
  「尚未交差」离开确认；同角色同时只挂一件委托、一次对话最多一件新 offer。
- **人物 CG** `js/cgdata.js`：六张二次元立绘（`assets/cg/` 原图，`tools/pack-cg.py`
  裁水印 → 480px → JPEG q72 → base64 内嵌）。留念物时刻对话框换 CG，
  手账「熟悉的人」里拿过留念物的常驻 CG。
- **音乐**：五章五种情绪（warm / calm / melancholy / night / tender），
  每种情绪两套琶音按小节交替；留念物有专属五声音阶短句（`sfx('keepsake')`）。
  依旧全程序化合成，零音频文件。
- **剧情层** `js/story.js`：五章 138 节点，0 选项，14 处函数式分岔（摊开后 152 条出边），6 种结局。
- 成就扩到 17 枚：剧情 8 + 漫游 9——把校园走遍 / 都打过招呼 / 帮上忙了 / 两手之间 /
  角落里的小东西 / 熟到不能再熟 / 六个都到了 / 这一学期的事 / 口袋更深了。
- 熟络度、委托进度、道具、留念物、解锁窗口都挂在存档的 `world` 区块，随既有存档系统自动保存；
  老存档 `ensure()` 会自动补齐缺的字段、剔掉已经不存在的条目。
- 存档 key 为 `sp4:`。
- 视觉延续纸墨主题，漫游组件全部走 `--ui-*` 变量，夜读模式自动适配，
  支持 `prefers-reduced-motion` 与窄屏。

## 打包

两条链都不依赖 Gradle / Android Studio / electron-builder，只用系统里现成的东西：

```bash
node tools/pack-desktop.mjs   # 电脑版 → ../成品/留一盏灯·漫游版（电脑版）/
node tools/pack-android.mjs   # 安卓版 → ../成品/留一盏灯·漫游版.apk
```

两个脚本都会比对 `index.html` / `js/` / `css/` 与 `dist/` 的 mtime：源码比产物新就自动重建，
不会把过期的那份打进包里。

- **电脑版**：Electron 便携版。换名的 `electron.exe` + `resources/app/`，
  `app.setPath('userData', exe 旁的「存档与设置」)` 让存档跟着包走；F11 全屏、单实例锁、
  后台不节流。图标与版本资源用 `rcedit` 刷进 exe。
- **安卓版**：`aapt2 compile` → `aapt2 link -A assets` → `javac -source 8 -target 8
  -bootclasspath android.jar` → `d8` → .NET ZipArchive 追加 `classes.dex` → `zipalign -p 4`
  → `apksigner` 自签 v1+v2+v3。外壳是一个 WebView Activity：用
  `loadDataWithBaseURL("https://lamp.local/", …)` 的虚拟源保证 localStorage 一定落盘，
  返回键翻译成游戏自己的收口动作（`window.__shellBack`），屏幕常亮、沉浸式全屏、锁定横屏。
- 图标由 `tools/make-icons.py` 用 Pillow 程序化绘制（灯 + 纸），同一份绘制函数导出
  `.ico` 多尺寸与安卓五档密度 mipmap（含圆形）。

## 自查范围（可复现）

```bash
node tools/verify-all.mjs --shots
```

十步全绿：

1. **语法** — 14 个 JS 模块 `node --check`。
2. **API 一致性** — `SP.ns.member` 调用全部对得上导出（识别 4 种导出写法）。
3. **剧情图** — 138 节点可达、6 结局可达、无断链 / 孤儿 / 非法取值，并断言分段与扁平文本一致。
4. **美术结构** — 14 场景四层 SVG 合法。
5. **单文件打包** — 无外链、无外部请求。
6. **CSS 压缩等价性** — `tools/check-css.mjs`：让 Chrome 分别解析压缩版与原样版样式表，
   逐条规则比对。此前打包器的压缩器存在静默破坏 CSS 的 bug（连后代选择器 `.j-face .dots`
   都会被压坏，共丢 222 条声明），本工具因此而生；已回归验证能抓住该 bug。
7. **运行时探针** — `tools/probe.mjs` 33/33（封面、推进、存读档、结局、面板、
   1536 组 flag 取样下 14 处函数式分岔全部落到真实节点）。
8. **漫游玩法探针** — `tools/probe-roam.mjs` 47/47（闸门进入 → 看一看 → 地图旅行 →
   三次对话走完「答应 / 办事 / 交差」→ 互斥作废 → 道具链三步取交 → 好感满值留念物 →
   手账作废栏 → 口袋三层 → 「还有事没定」确认 → 回主线 → 存档含 world）。
9. **预览截图** — 19 张（含漫游 / 地图 / 手账 / 口袋），见 `dist/shots/`。
10. **截图体检** — 逐像素解码，尺寸 / 亮度 / 主色合理。

**限制**：以上为 DOM 自动化与渲染检查；音频听感、长局存档轮换仍建议人工过一遍。
