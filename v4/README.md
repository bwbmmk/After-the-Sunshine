# 留一盏灯 · 漫游版

《晴天以后》的新篇章。一学期、一部还没剪完的短片，以及几个慢慢熟悉的人。

在完整的五章剧本之上，加入**自由行动 / 可交互人物 / 校园地图 / 委托手账**四层玩法：
主线一字不改，课余时间交给你自己安排。

## 开始

双击 `dist/留一盏灯·漫游版.html`。不需要安装、不需要联网。

已经打好的成品在 `../成品/`：

| 用途 | 文件 |
| --- | --- |

## 玩法

**主线**：点一下补完文字，空格或 Enter 推进，数字键选选项，返回按钮回退。

**漫游**：主线走到章节边界会进入「自由行动」——

- **画面上直接点人物**：场景里的圆头像就是此刻在这里的人，点谁和谁聊。首次见面有专门的打招呼，常聊天会提升熟络度（每人满 5 心）。
- **M 打开校园地图**：14 处地点的手绘导览，点哪里去哪里；橙点表示那里有委托找你，★ 是当前主线目的地。旅行免费，随时回主线。
- **J 打开任务手账**：10 个小委托，每个 2–3 步（找人 / 去某地 / 看某物），完成后回去交差，会收进一张手记并提升熟络度。手账里还汇总「听说的事」。
- **口袋**：主线纸片 + 委托手记，两个册子并排放在同一个面板里。

五个自由行动窗口（报到日 / 社团招新后 / 十一月 / 期末前 / 放映前）各有独立的人物分布、委托与对白；主线节奏不受影响，随时点「继续主线」即可回到剧情。

## 文本分层

对白、旁白、心声是三种不同的声音，数据与渲染都分开处理。

- **写作侧**用四个构造器：`D()` 对白 · `S(who, …)` 旁白里提到某人 · `N()` 旁白 · `I()` 心声。节点不再是一坨字符串，而是一串带 kind 的段。
- **兜底**：老写法（一整段纯文本）仍然能用。`bare(text, who)` 扫描中文引号 `“ ” 「 」` 的嵌套深度，自动把它切成旁白 / 对白，所以漏写分段也不会露馅。
- **双轨产出**：`beat()` 一次性生成 `node.seg`（分段，渲染用）与 `node.text`（扁平字符串，故事记录 / 导出 / 旧存档都读它）。`validate-story.mjs` 里加了永久断言，两者一旦漂移就报错。
- **渲染**：`engine.setText(segs)` 为每一段建一个 `<span class="seg seg-{k}">`，打字机按「整串偏移」灌字，所以逐段显示不会串行。
- **视觉**走三个通道：明度（旁白压到 72%）、字重（对白 600）、字体（心声走衬线）；六位常出场人物再叠一层 `[data-who]` 色相偏移。全部用 `color-mix()` 写，夜读界面自动跟着变。

当前剧本里共 295 段旁白、135 段对白、136 段心声，138 个节点全部含两种以上声音。

## 本版内容

- **玩法层**：`js/game.js`（世界状态 / 14 地点 / 13 条道路 / 10 委托 / 6 人物 / 5 新成就）+ `js/roam.js`（漫游呈现 / 对话队列 / 地图 / 手账）+ `css/game.css`。
- **剧情层**：五章 138 节点、14 次选择、29 个选项、6 种结局，结局由 flags 动态结算。
- 成就扩到 13 枚：剧情 8 + 漫游 5（探索地点、打招呼、交差、全部委托、集齐手记）。
- 熟络度、委托进度、解锁窗口都挂在存档的 world 区块，随既有存档系统自动保存；导出备份一并带走。
- 存档 key 为 `sp4:`。
- 视觉延续纸墨主题，漫游组件全部走 `--ui-*` 变量，夜读模式自动适配，支持 `prefers-reduced-motion` 与窄屏。

## 打包

两条链都不依赖 Gradle / Android Studio / electron-builder，只用系统里现成的东西：

```bash
node tools/pack-desktop.mjs   # 电脑版 → ../成品/留一盏灯·漫游版（电脑版）/
node tools/pack-android.mjs   # 安卓版 → ../成品/留一盏灯·漫游版.apk
```

- **电脑版**：Electron 便携版。换名的 `electron.exe` + `resources/app/`，`app.setPath('userData', exe 旁的「存档与设置」)` 让存档跟着包走；F11 全屏、单实例锁、后台不节流。图标与版本资源用 `rcedit` 刷进 exe。
- **安卓版**：`aapt2 compile` → `aapt2 link -A assets` → `javac -source 8 -target 8 -bootclasspath android.jar` → `d8` → .NET ZipArchive 追加 `classes.dex` → `zipalign -p 4` → `apksigner` 自签 v1+v2+v3。外壳是一个 WebView Activity：用 `loadDataWithBaseURL("https://lamp.local/", …)` 的虚拟源保证 localStorage 一定落盘，返回键翻译成游戏自己的收口动作（`window.__shellBack`），屏幕常亮、沉浸式全屏、锁定横屏。
- 图标由 `tools/make-icons.py` 用 Pillow 程序化绘制（灯 + 纸），同一份绘制函数导出 `.ico` 多尺寸与安卓五档密度 mipmap（含圆形）。

## 自查范围（可复现）

```bash
node tools/verify-all.mjs --shots
```

十步全绿：

1. **语法** — 13 个 JS 模块 `node --check`。
2. **API 一致性** — `SP.ns.member` 调用全部对得上导出（识别 4 种导出写法）。
3. **剧情图** — 138 节点可达、6 结局可达、无断链 / 孤儿 / 非法取值，并断言分段与扁平文本一致。
4. **美术结构** — 14 场景四层 SVG 合法。
5. **单文件打包** — 无外链、无外部请求。
6. **CSS 压缩等价性** — `tools/check-css.mjs`：让 Chrome 分别解析压缩版与原样版样式表，逐条规则比对。此前打包器的压缩器存在静默破坏 CSS 的 bug（连后代选择器 `.j-face .dots` 都会被压坏，共丢 222 条声明），本工具因此而生；已回归验证能抓住该 bug。
7. **运行时探针** — `tools/probe.mjs` 31/31（封面、推进、选择、存读档、结局、面板）。
8. **漫游玩法探针** — `tools/probe-roam.mjs` 26/26（闸门进入 → 看一看 → 地图旅行 → 接委托 → 推进 → 交差 → 手账 → 口袋 → 回主线 → 存档含 world）。
9. **预览截图** — 18 张（含漫游 / 地图 / 手账），见 `dist/shots/`。
10. **截图体检** — 逐像素解码，尺寸 / 亮度 / 主色合理。

**限制**：以上为 DOM 自动化与渲染检查；音频听感、长局存档轮换仍建议人工过一遍。
