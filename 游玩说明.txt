三种打开方式，内容完全相同，挑顺手的用：

① 电脑（免安装绿色版）
   成品/留一盏灯·漫游版（电脑版）/留一盏灯·漫游版.exe
   双击开玩。不安装、不联网、不写注册表。存档就放在 exe 旁边的
   「存档与设置」文件夹里 —— 整个文件夹拷到 U 盘或另一台电脑，
   进度跟着走，不用重新开始。

② 手机（安卓 APK）
   成品/留一盏灯·漫游版.apk
   拷进手机点开安装，需要 Android 5.0 及以上。首次安装系统会提示
   「未知来源」——这是自签名应用的正常提示，允许即可。

③ 浏览器（单文件）
   成品/留一盏灯·漫游版（网页版）.html
   双击用浏览器打开就能玩。想单独发给别人时，这一份最省事。

────────────────────────────────────────────
玩法
  主线   点一下补完文字，空格 / Enter 推进。
         主线里已经没有当场选项了——十四处分岔各剩一段旁白，
         往哪边走，看你在这个月把时间花在了谁身上。

  漫游   每章之间会进入「自由行动」——
         · 直接点画面上的人聊天。第一次见面会打招呼，聊得多了会变熟
           （每人满 5 心）。光聊天最多攒到 4 心——剩下那一心
           要靠给他办成一件委托，他会把话说明白。满 5 心以后
           再说一次话，会拿到这个人给你的专属留念物，每人只有一件。
           妈妈每个月都会打电话来（在四号楼接），别漏接；
           就算一月那通没接到，只要前面攒到 4 星，
           散场时她还会再打来一次，把配方直接交给你。
           周老师十月到十二月在教学楼，一月在礼堂。
         · M 打开校园地图：14 处地点随便走，橙点是有委托找你，
           ★ 是主线目的地，小亮点是那儿有个能顺手捡的东西。
         · J 打开任务手账：手上的委托、这个月没做的、听说的事、
           已完成、口袋速览、六个人的熟悉度。
         · ▤ 口袋：分三栏——手上的事 / 留念 / 角落里的小东西。
           每件都可以点开检视，留念物会配上那个人的 CG。

  精力有限  29 条委托分成 10 个互斥组。接了组里的一件，
         同组其余几件这个月就作废（手账里会标成「这个月没空」）。
         不是让你全做完，是让你选——每组正好对应一处主线分岔。

  道具   别人递过来的东西会真的收进口袋，交差时再给出去。
         有几条链跨了好几个人、甚至跨了两个月：
           程野 → 陈姨 → 程野（螺丝 → 垫片 → 铁盒）
           陈姨 → 阿言 → 陈姨（草稿 → 打印 → 复印件，五步）
           十月拿到的编号胶带，十二月才用得上；
           十二月那份复印件，一月才归进阿言的交接文件夹。

  彩蛋   14 处地点各藏一件校园小物，点「✦ 看看这里」就能顺手捡到。
         没有用途，纯收集，每件都有一段正经里带点毛病的说明。

  快捷键  空格 / Enter 推进 · M 地图 · J 任务手账 · H 帮助
  规模    一学期五章 · 141 个剧情节点 · 0 个当场选项 · 15 处分岔
          · 6 种结局 · 29 条委托 · 31 件物品 · 17 枚成就

  文本分成三种声音：旁白偏灰、对白偏重、心声走衬线斜调。
  六个常出场的人物各有自己的色相，一眼能分出是谁在说话。

────────────────────────────────────────────
存档
  电脑版      exe 旁边的「存档与设置」文件夹
  安卓 / 网页  浏览器本地存储（安卓版挂在 https://lamp.local/ 虚拟源下）

  三边的存档互不相通。想清空重玩，删掉对应的那份即可，游戏本体不受影响。
  游戏内「设置 → 数据 → 导出」可以把全部存档、图鉴、成就导出成一个
  JSON 文件；换设备或换版本时用「导入」接着玩。

────────────────────────────────────────────
源码与自检
  v4/ 目录：14 个 JS 模块 + 5 份 CSS + tools/ 里的一套自检脚本。

  在 v4 目录运行
      node tools/verify-all.mjs --shots
  可复现十步全量校验，全绿：
    语法 → API 一致性 → 剧情图 → 美术结构 → 单文件打包
    → CSS 压缩等价性 → 运行时探针 33 项 → 漫游玩法探针 47 项
    → 19 张截图 → 截图体检

  重新打包
      node tools/pack-desktop.mjs    电脑版（Electron 绿色版）
      node tools/pack-android.mjs    安卓版（aapt2 + d8 + apksigner 手搓，不用 Gradle）
  两条链的依赖位置与说明都写在各自脚本开头。
