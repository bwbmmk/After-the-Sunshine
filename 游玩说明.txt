《晴天以后》· 留一盏灯 · 漫游版
════════════════════════════════════════════════

三种打开方式，内容完全相同，挑顺手的用：

① 电脑（免安装绿色版）
   成品/留一盏灯·漫游版（电脑版）/留一盏灯·漫游版.exe
   双击开玩。不安装、不联网、不写注册表。存档就放在 exe 旁边的
   「存档与设置」文件夹里 —— 整个文件夹拷到 U 盘或另一台电脑，
   进度跟着走，不用重新开始。

② 手机（安卓 APK）
   成品/留一盏灯·漫游版.apk
   拷进手机点开安装，需要 Android 5.0 及以上。首次安装系统会提示
   「未知来源」——这是自签名应用的正常提示，允许即可。

③ 浏览器（单文件）
   成品/留一盏灯·漫游版（网页版）.html
   双击用浏览器打开就能玩。想单独发给别人时，这一份最省事。

────────────────────────────────────────────
玩法
  主线   点一下补完文字，空格 / Enter 推进，数字键选选项。
  漫游   每章之间会进入「自由行动」——
         · 直接点画面上的人聊天，聊得多了会变熟
         · M 打开校园地图，14 处地点随便走，橙点是有委托找你
         · J 打开任务手账，10 个小委托：接下、做、回去交差

  快捷键  空格 / Enter 推进 · M 地图 · J 任务 · H 帮助
  规模    一学期五章 · 138 个剧情节点 · 14 次选择 · 6 种结局

  文本分成三种声音：旁白偏灰、对白偏重、心声走衬线斜调。
  六个常出场的人物各有自己的色相，一眼能分出是谁在说话。

────────────────────────────────────────────
存档
  电脑版      exe 旁边的「存档与设置」文件夹
  安卓 / 网页  浏览器本地存储（安卓版挂在 https://lamp.local/ 虚拟源下）

  三边的存档互不相通。想清空重玩，删掉对应的那份即可，游戏本体不受影响。
  游戏内「设置 → 数据 → 导出」可以把全部存档、图鉴、成就导出成一个
  JSON 文件；换设备或换版本时用「导入」接着玩。

────────────────────────────────────────────
源码与自检
  v4/ 目录：13 个 JS 模块 + 5 份 CSS + tools/ 里的一套自检脚本。

  在 v4 目录运行
      node tools/verify-all.mjs --shots
  可复现十步全量校验，全绿：
    语法 → API 一致性 → 剧情图 → 美术结构 → 单文件打包
    → CSS 压缩等价性 → 运行时探针 31 项 → 漫游玩法探针 26 项
    → 18 张截图 → 截图体检

  重新打包
      node tools/pack-desktop.mjs    电脑版（Electron 绿色版）
      node tools/pack-android.mjs    安卓版（aapt2 + d8 + apksigner 手搓，不用 Gradle）
  两条链的依赖位置与说明都写在各自脚本开头。
